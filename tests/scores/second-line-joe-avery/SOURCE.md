# (The Original) Second Line (Joe Avery's Blues)

- **Composer:** traditional New Orleans march (credited "New Orleans March").
- **Edition:** David Berger and Chuck Israels (eds.),
  *The Public Domain Song Anthology*, Aperio, 2020.
- **Category:** jazz lead sheet with slash comping.

## Source

- Book: <https://doi.org/10.32881/book2>
- Dataset (per-song PDF, XML, Sibelius files), UVA Dataverse:
  <https://doi.org/10.18130/V3/C4RD06>
- Files, downloaded 2026-09-29:
  - XML: <https://dataverse.lib.virginia.edu/api/access/datafile/3747>
  - PDF: <https://dataverse.lib.virginia.edu/api/access/datafile/4633>
  - SIB: <https://dataverse.lib.virginia.edu/api/access/datafile/4279>

## Files

`.xml` (MusicXML 3.0, direct Sibelius export), `.pdf`, `.sib`;
all three were generated from the same Sibelius source, per the dataset READMEs.
Kept byte-for-byte and under their distributed names.

## Notable features

One part with chord symbols (`<harmony>`), first and second endings,
and a "Send-off" section written as slash noteheads with one-bar
`<measure-repeat>` over the changes (rhythmic comping over an open vamp).
There is no D.S./Coda and no labelled solo section.
