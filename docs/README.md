# Building the documentation

The docs are a [Quarto](https://quarto.org) website.
Pages with code samples are executable `.qmd` files;
their code runs at build time against the installed package,
so a broken example breaks the build.
The API reference is generated by [quartodoc](https://machow.github.io/quartodoc/)
from the docstrings; the module order is set in `_quarto.yml`.

Both tools are dev dependencies, installed by `uv sync`.
Run everything from this directory through `uv run`
so Quarto finds the project's virtualenv.

```bash
cd docs
uv run quarto preview     # build, serve on localhost, rebuild on change
uv run quarto render      # build only, into docs/_site/
```

Both commands run `quartodoc build` first (the `pre-render` step in `_quarto.yml`),
which writes the `reference/` pages and `reference/_sidebar.yml`.
Everything generated (`reference/`, `_site/`, `.quarto/`) is gitignored.
